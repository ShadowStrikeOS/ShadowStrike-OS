# Assets

`org-logo-globe-suit.jpg` is the organisation logo: the globe-head operator.
It is the wallpaper and lock screen source for ShadowStrike OS.

Static use rules, from the flagship theme spec:

- Never recoloured. The mark is silver on black, exactly as supplied.
- Never stretched or cropped into a different aspect.
- Never placed on a light background.
- Centred on a black field (#050505 to #0A0A0A) with room to breathe.

Green belongs to live surfaces (terminal, HUD, MOTD). Silver is the mark.
